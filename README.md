# Terminal Portfolio

Portfolio personal con estética de terminal Linux.

El sitio simula una sesión CLI donde los proyectos se renderizan dinámicamente desde un archivo Markdown, manteniendo una experiencia minimalista y coherente con un perfil técnico orientado a infraestructura y automatización.

---

## Concepto

La idea no es construir una landing tradicional, sino representar la identidad profesional a través de una interfaz familiar para entornos técnicos: la terminal.

Cada sección se presenta como si fuera parte de una sesión real de comandos, priorizando simplicidad, legibilidad y enfoque funcional.

---

## Stack

- HTML5
- CSS3 (Custom Properties + Flexbox)
- JavaScript (ES6)
- Marked.js para renderizado Markdown

---

## Objetivo

Explorar una forma alternativa de presentar proyectos técnicos sin depender de frameworks pesados ni elementos visuales innecesarios.

Minimalismo.  
Claridad.  
Ingeniería antes que decoración.
